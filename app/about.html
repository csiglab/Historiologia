About Historiologia

Laboratorium Maius Studiorum Historiologiae — a collaborative research hub dedicated to the advanced study, preservation, and dissemination of Hispanic cultural, historical, and literary heritage, with comparative notes on the wider world.

Scope

  • Castilla — the Hispanic core and its global context: institutions, economy, law, religion, culture.
  • Breviarium — short clarifying essays.
  • Portugal, Russian Empire, Soviet Union — comparative imperial notes.

Method

Each topic is a long-form note (.md, rendered on the fly) or a live note (.html, bespoke interactivity such as the atlas). The catalog is the navigator — browse by section, filter by tag, live and unfinished facets, full-text search. The atlas shows the corpus by volume. Every page shares the same navigation bar, footer, theme and typography.

Contributing a note

Place a kebab-case file under app/note/data/<section>/, e.g. castilla/reformas-borbonicas.md. Title comes from the first # heading; optional tags go in front matter:

---
tags: [economia, fiscalidad]
---

Mark stubs with the reserved unfinished tag. Link internally with [Name](target-note.md); keep references as ordinary markdown links. Then run make index and commit the regenerated indexes alongside the note, with one changelog entry per touched file in app/note/data/changelog.json. See spec/note/authoring.md and AGENTS.md.

Technology

Static-first: hand-edited markdown, prebuilt index.json / search-index.json / landing-metrics.json (stdlib Python builders in bin/), vanilla HTML/CSS/JS viewer with vendored marked and KaTeX — no build step, no database. The thin app.py server (stdlib http.server) serves app/ plus a read-only /api/health, /api/search, /api/index; any static host serves the same files.

Colophon

Design system: Oxford Common Room — Cormorant Garamond (display italic), Inter (body), JetBrains Mono (labels); dark void with copper/cyan, parchment light theme. Viewer machinery ported from the Naturgnosis note system (code only; none of its content).
